Transformer Attention Pipeline Flowchart

1. Load Raw Text

Reads entire Shakespeare text from:

with open('input.txt', 'r') as f: text = f.read()

Suppose:

text = "hello world"

Every unique character becomes part of vocabulary.

vocab_size = number of unique characters

↓
2. Character Tokenization
stoi = { ch:i for i,ch in enumerate(chars) } itos = { i:ch for i,ch in enumerate(chars) }

Example:

h → 0 e → 1 l → 2 o → 3

Encoding:

"hello" → [0,1,2,2,3]

Final Tensor Shape:

data.shape = (total_tokens,)
↓
3. Train / Validation Split
n = int(0.9 * len(data)) train_data = data[:n] val_data = data[n:]

90% training
10% validation

↓
4. get_batch()

Randomly samples training sequences.

batch_size = 32 block_size = 8

Input:

x.shape = (32, 8)

Target:

y.shape = (32, 8)

Each row contains 8 characters.

Targets are shifted by 1 token.

x: "hello wo" y: "ello wor"
↓
5. Enter BigramLanguageModel.forward()
logits, loss = model(xb, yb)

Input Tensor:

idx.shape = (B,T) = (32,8)
↓
6. Token Embedding Lookup
self.token_embedding_table = nn.Embedding(vocab_size, n_embd)

Hyperparameter:

n_embd = 32

Every token becomes a learned vector of size 32.

Transformation:

(32,8) → (32,8,32)

Meaning:

(Batch, Time, Embedding)
↓
7. Positional Embeddings
self.position_embedding_table = nn.Embedding(block_size, n_embd)

Adds position awareness.

Without this: Transformer cannot know token order.

Position 0 → vector Position 1 → vector ... Position 7 → vector

Shape:

pos_emb.shape = (8,32)
↓
8. Combine Token + Position Embeddings
x = token_emb + pos_emb

Broadcasting:

(32,8,32) + (8,32) → (32,8,32)

Now every token contains:

  • semantic meaning
  • position information
↓
9. Enter Self-Attention Head
x = self.sa_head(x)

Input Shape:

(B,T,C) = (32,8,32)
↓
10. Linear Layers → K, Q, V
self.key = nn.Linear(32,32) self.query = nn.Linear(32,32) self.value = nn.Linear(32,32)

Each token vector passes through 3 separate learned matrices.

Outputs:

k.shape = (32,8,32) q.shape = (32,8,32) v.shape = (32,8,32)

Meaning

  • Q (Query) → What am I looking for?
  • K (Key) → What information do I contain?
  • V (Value) → Actual information to pass
↓
11. Attention Score Calculation
wei = q @ k.transpose(-2,-1)

Shapes:

q = (32,8,32) k.T = (32,32,8)

Matrix Multiplication:

(32,8,32) @ (32,32,8) → (32,8,8)

Now every token has a score against every other token.

This is the attention matrix.

Interpretation

Token i asks: "How important is token j to me?"
↓
12. Scaling
wei = wei * (head_dim ** -0.5)

Prevents exploding attention values.

You originally used C instead of head_dim.

↓
13. Causal Masking
wei = wei.masked_fill( tril == 0, float('-inf') )

Prevents future token leakage.

Example

Token 4 cannot see token 5,6,7

Upper triangle becomes:

-inf
↓
14. Softmax
wei = F.softmax(wei, dim=-1)

Converts attention scores into probabilities.

Shape remains:

(32,8,8)

Each row sums to 1.

↓
15. Weighted Aggregation
out = wei @ v

Shapes:

wei = (32,8,8) v = (32,8,32)

Output:

(32,8,32)

Each token now contains information gathered from previous tokens.

This is Contextual Understanding

Now token representations are no longer isolated. They are context-aware.

↓
16. Final Language Modeling Head
logits = self.lm_head(x)
nn.Linear(32, vocab_size)

Transformation:

(32,8,32) → (32,8,vocab_size)

Every token predicts probability distribution over all characters in vocabulary.

↓
17. Cross Entropy Loss
loss = F.cross_entropy(logits, targets)

Model prediction vs actual next token.

Single scalar loss generated.

↓
18. Backpropagation
loss.backward() optimizer.step()

Gradients flow backward through:

  • lm_head
  • attention weights
  • K/Q/V matrices
  • embedding tables

All parameters update slightly.

↓
FINAL BIG PICTURE
Raw Text ↓ Character Tokenization ↓ Integer Sequences ↓ Batch Sampling ↓ Token Embeddings ↓ Position Embeddings ↓ Add Together ↓ Self Attention Head ↓ K,Q,V Projections ↓ Attention Scores ↓ Masked Softmax ↓ Weighted Value Aggregation ↓ Context Aware Representations ↓ Linear Vocabulary Projection ↓ Logits ↓ Cross Entropy Loss ↓ Backpropagation ↓ Updated Weights
